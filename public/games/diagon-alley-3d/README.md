# 对角巷 3D · 魔法夜巡

第一人称漫游哈利波特的对角巷（Three.js r160，纯静态页面，无需构建）。

## 玩法
- WASD 移动，鼠标环顾，Shift 奔跑；E 开门、互动、与角色交谈
- 左键挥动魔杖施咒，1–4 / 滚轮切换咒语（除你武器 · 荧光闪烁·最强 · 火焰熊熊 · 呼神护卫），L 荧光闪烁
- V 切换魔杖（老魔杖 / 德拉科的山楂木魔杖），N 切换白天 / 夜晚，T 自动巡游，M 地图
- **骑士公共汽车**：在街心往返，速度时快时慢；遇到行人会把车身挤窄；在中段站停 10 秒。车停时走到车尾按 E 上车，自动乘坐一圈，到站按 E 下车；也可以和售票员斯坦、司机厄恩交谈

## 资源与优化
- `assets/models/`：用户提供的 GLB / OBJ / STL 模型，已离线减面（每个 ≤ 2.4 万面），压缩为 meshopt 几何 + WebP 贴图，全部模型合计约 4 MB
- 没有骨骼的静态人形模型（哈利、罗恩）在加载时自动绑骨，可以走路、摆臂、转头
- 灯光池：场景登记了上百个光源，但只用 12 个真实 PointLight，按离镜头的距离动态分配
- 嵌入作品集时，收到 `cty:game-visibility` 消息后会暂停渲染
