# 月面作品馆

双击桌面月球（手机双点，键盘 Enter）进入月面作品馆。使用现有作品索引的 32 件作品、8 个分类，排除尚无内容的占位项目。金边相框使用实际作品封面；接星星补充星空场景卡片。点击展牌调用原来的桌面应用入口。

- 入场：有限时长的星光拉伸、月球推进与立体月面显现；到达后移除过场 DOM。
- 月面：奶油金与蓝色马赛克立方体、凸起瓷片、金色轨道、极点小猫与像素碎片尾迹。
- 浏览：缓慢自转、指针/触屏拖动、惯性、悬停提示、暂停自转、分类与两组展区。底部显示当前作品；方向键将展牌转到正面，Enter 打开。完整列表提供键盘和小屏幕替代入口。
- 性能：月面组件仅进入后加载；只请求小封面，不预加载 iframe、游戏或模型。每次最多 18 张展牌、最多 3 个并行封面请求。手机使用 3,010 个批量瓷片、约 41,112 个三角形；桌面 5,288 个瓷片、约 68,448 个三角形。均不启用实时阴影和全屏后处理。
- 生命周期：后台页签暂停帧时钟；进入月面时沿用已有桌面/应用暂停机制。退出取消封面请求、释放几何/纹理/位图及渲染器。切换分类取消旧分类请求。支持减少动态效果；WebGL 不可用或丢失时保留可打开作品的相册视图。
- 手机：全屏独立布局、可横向滑动分类栏、固定底部作品控件和触屏旋转；画幅适应横屏、竖屏和安全区。

## 验证

`node scripts/qa/moon-gallery.cjs` 检查全部作品/封面路径、分页和分类完整性、354 个球面姿态及不同画幅的相框取景、正面命中与背面遮挡、几何预算和按需入口。

同时执行 TypeScript 检查、现有动画生命周期/桌面性能回归及正式构建。当前环境没有本站的浏览器 QA，未声称真实手机帧率或视觉逐像素一致。参考站浏览在后续检查时遇到审批服务 429；设计依据用户提供的月面作品馆截图及已观察到的页面。

主站与 GitHub main、kimi-deploy 同步；不改变 Kimi 的独立部署配置，也不把此前报告的 Kimi 白屏标记为已解决。
