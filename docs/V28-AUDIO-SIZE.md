# v28 音效与资源体积

## 已完成的主站更新

- 桌面的 16 种提示音改为柔和的正弦 / 三角波短音。盾牌和碰撞使用轻铃音，魔法与烟花使用短琶音，去掉突然的爆破噪声和低频冲击。
- 降低总增益，加入柔和起音、低通和动态压缩；最多同时保留 12 个声部，限制重复触发。音乐播放时进一步降低桌面音效，继续支持静音、页面隐藏暂停和用户交互后启用。
- 内置时空游戏降低切换、落地与失败音效；玩具小城降低吼声、碰撞和碎裂音量；鹈鹕车铃降低音高与音量、限制连续点击；艺术漫游降低可选环境声音。歌曲文件及用户播放器音量未修改。外部嵌入站点的音效不在本次修改范围内。
- 统一显示名称为“文艺复兴”。迁移本地保存的旧默认名称；旧称仍可作为搜索别名识别。应用 ID、两个漫游入口和自定义命名不变。
- 将 8 张已停用的 PNG 原图移至 `archive/source-art`，保留在源码和 GitHub 中；部署继续使用已有 WebP 展示版本。静态发布资源减少 7,337,184 字节，未缩减运行画面细节。

## 体积核查

按源码 `public/` 文件实际字节统计，单位 MB = 1,000,000 字节。这是静态素材总量，不是首屏传输量、JavaScript 包大小或压缩部署包大小。

| 项目 | 调整前静态资源 | 本轮结果 |
| --- | ---: | --- |
| CTY AI STUDIO | 183.79 MB | 约 176.45 MB，原始素材归档不再进入静态发布目录 |
| AI 研习所 / AI-cat | 41.99 MB | 本轮只审查与压缩试验，未修改或发布该站 |

主站多数体积来自按应用打开后才需要的作品、视频、Python 运行时、Minecraft 模型与歌曲。AI 研习所是独立站点，并未把它的 42 MB 资源重复打进主站。保留现有按需挂载、媒体不预加载和不可见窗口暂停机制，比单纯削减素材总量更影响首次进入桌面的体验。

AI 研习所可优先处理：

1. **图片。** 图片约 21.86 MB；六张 PNG 原尺寸无损 WebP 试验从 14,448,807 字节降至 10,847,562 字节，节省 3,601,245 字节（24.9%）。首页直接引用的 3D 图片原本 2.41 MB；另可制作适配卡片尺寸的展示版本，同时保留高清原件。
2. **代码拆分。** `hub.tsx` 已延迟加载三个实验室，其余多个工作台仍是静态导入，可继续按页面拆分。已打开标签通过 `forceMount` 保留，需要逐项确认不可见时暂停图形 / 定时任务，不能只隐藏界面。
3. **媒体。** 视频约 11.21 MB，下载资料约 8.92 MB。继续在打开相应作品或点击下载时加载；视频可另设预览版本。PDF 本身只由用户点击链接打开，不属于首页必需下载。
4. **模型。** 本机模型在用户点击“下载并启用本机模型”后才导入 WebLLM 并下载；模型权重不在上述 41.99 MB 内。不要为了所谓预加载而自动下载模型。

本轮没有对大模型、三维场景或歌曲做有损重压缩，也未测量真实网络首屏传输量或手机帧率。
