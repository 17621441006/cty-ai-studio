# V35 — 月光脏脏包图标与超Q相册

- 网站默认图标使用用户选定的完整橘色波斯猫与蓝白月球图案，仅缩放导出，不重绘。
- iPhone 使用明确声明的 180×180 PNG `apple-touch-icon`，同时提供根目录兼容入口；浏览器使用 PNG/ICO 图标，安装清单提供 192 和 512 像素版本。
- 安装名称为 CTY AI，网站完整名称仍为 CTY AI STUDIO。主屏幕以独立网页应用方式打开。
- 图标与配置已纳入源码，正常更新内容和重新部署时保持。图标文件带固定版本号，将来更换图案时递增，避免复用旧资源地址。
- iOS 已安装图标的缓存由系统管理，网站不能强制刷新所有现有桌面入口。如果旧入口仍显示 C，可先在 Safari 打开网站，再通过分享菜单重新“添加到主屏幕”。
- 相册的桌面名称、窗口标题、加载提示、月面展牌和相册页标题统一为“超Q相册”。搜索保留“相册”“AI Q版相册”等旧名称；旧官方名称的本地偏好迁移到新名称，自定义昵称保持。
- 独立部署分支同时增加 HTML 图标声明，以及 webmanifest 和 ICO 的响应类型。

验证范围：PNG 尺寸及不透明背景、元数据实际渲染结果、安装清单资源存在性、相册搜索目标、TypeScript 和生产构建。未进行 iPhone 真机安装与系统图标缓存刷新验证。
