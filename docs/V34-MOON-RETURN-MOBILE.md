# V34 — 月面翻转与原位返回

月面相框使用现有 Three.js 场景翻转：悬停轻抬，约每 7.5 秒选一张朝向镜头的相框翻面，点击时播放 0.78 秒翻转再打开作品。背面带作品分类与名称。一次仅一张相框翻转，不增加三维模型下载或后期特效；减少动态效果偏好下直接打开。

从月面打开的作品窗口带“返回月面”按钮。关闭或最小化当前作品，也会返回月面。分类、展区、选择和月球旋转角度保留，返回时不重播入场动画。作品打开期间月面 WebGL 场景卸载，释放 GPU 资源；显式点击“桌面”才结束本次月面浏览。较早窗口的关闭定时器不会打断后来打开的作品。

手机首页使用同一行显示 CTY AI STUDIO 和本地时间；下方为随时段变化的问候、日期和独立月相区。夜间加入“夜深了，还没睡？”及“这么晚了还没睡？”的问候。

## 验证

- TypeScript 无输出增量文件的类型检查。
- `node scripts/qa/moon-gallery.cjs`：32 件作品与封面、354 组屏幕比例/球面位置、背面遮挡，481 个翻转姿态的月面碰撞检查，嵌套打开/延迟关闭/显式返回桌面的导航回归，七个问候时段。
- `node scripts/qa/performance.cjs`：隐藏窗口、月面后台暂停、帧时钟和音频 UI 更新隔离。
- Sites 生产构建与独立部署分支构建、部署文件检查及部署测试。

当前环境没有受支持的浏览器 QA 通道，未完成 iPhone 真机、鼠标交互和屏幕视觉验收；代码检查与构建不等同于这些验证。国内无需 VPN 的实际连通性也需要大陆网络实测。
