# v29 展示与角色更新

## AI 研习所

- 主站打开研习所时加载本地 React 展示页，不挂载 AI-cat 全站 iframe。包含可勾选的上下文练习、采购审单流程示例、可操作的表格清理，以及原站界面预览。
- 展示页不导入 WebLLM、Three.js、Worker 或原站工作台代码，没有远程数据请求、音视频预加载或常驻动画。唯一的展示图片是已有的本地 51 KB 封面，切换到相应预览后才挂载。
- 原站入口使用普通链接，不预取远程页面。点击后在原站加载完整功能。助手发来的合法页面与查询参数保留，点击继续学习会进入对应页面。
- 完整 AI-cat 网站以及 AI 小脏的原问答入口保持原来的功能和发布版本。

## 图标与角色

- BOBO / 脏脏包表情图标使用本次用户提供的“风中优雅”图片；原文件逐字节保存在 `public/assets/icons/bobo-wind-original.png`，仅在 SVG 显示时裁去截图边缘，图画没有重绘。当前表情合集的第一格也是同一表情；未找到可核实的更高分辨率独立原件。
- 接星星图标改为像素脏脏包与金星。游戏中的角色使用与像素音乐关卡相同的原角色图集；修正裁切范围，避免带入相邻角色的白边。
- 原黑猫绘制函数停止使用；维持本地规则、30 秒计时、星星连击、蓝方块扣 3 分与 0.7 秒眩晕。替换角色后统一视觉落脚点与碰撞范围，保留方向翻转和轻微脚步动作。
- 游戏代码与角色素材都在本主仓库，无需外部游戏站点。原始来源说明保留在 `original-stars/SOURCE.md`。

## 掉落猫叫

- v28 的全局防叠音间隔会让同一帧先触发的落地提示音挡住后触发的“喵”。掉落现在只发出猫叫，落到图标 / 窗口也一致；猫叫获得优先级，同时继续保留自身 1.6 秒防重复间隔。
- 恢复之前有元音变化的短猫叫合成方式，沿用降低后的音量、柔和起音和动态压缩。盾牌与魔法继续使用 v28 的柔和音效。
