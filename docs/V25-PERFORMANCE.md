# v25：城堡性能、烟花同步与手机图标

2026-10-05

## 修复

- 城堡建筑与遮挡层缓存到离屏画布；不再每帧重建五组裁剪并重复缩放原图。
- 动态窗灯从 497 个降至桌面 85 个、手机 47 个，分布覆盖各建筑；灯光合成层每秒更新 6 次，光晕缓存复用。水面与天空保留动态效果。
- 烟花按颜色批量绘制，取消逐粒子渐变和模糊，保留七组花型、金色余烬及周边绽放。限制粒子预算；高开销时进一步降低粒子密度。角色画布使用 1× 像素密度，角色随动画帧移动。
- 猫咪在地面走动时不再每帧扫描所有应用和窗口的位置；无变化的 CSS 和 React 状态不重复更新。跳跃、着陆和停靠仍使用实时接触位置。
- 火焰在施法阶段 1.40 秒到达目标；首朵烟花和音效共用这一时刻，中心与火焰顶端一致，消除原先约 1.3 秒等待和 98 像素偏移。
- 手机端的蓝色边框移入图标本身的容器，移除独立伪元素与继承的顶部偏移。图标、底框、名称保持同一列中轴线。

## 同机离屏性能对比

实际源码通过 TypeScript 转译后在 `@napi-rs/canvas` 软件光栅器中执行。每项预热 5 帧、采样 30 帧；单位毫秒。不是浏览器 FPS，也不是手机实机响应测量。

| 场景 | v24 中位 / p95 | v25 中位 / p95 |
| --- | --- | --- |
| 城堡 1440×852 | 16.228 / 19.544 | 2.569 / 4.222 |
| 城堡 390×760 | 10.146 / 11.708 | 1.058 / 1.628 |
| 烟花桌面，DPR 1，q=4.5 | 29.585 / 34.720 | 8.295 / 9.603 |
| 烟花手机，DPR 1，q=4.5 | 26.939 / 34.979 | 3.654 / 3.962 |

v24 实际还可能以 DPR 2 绘制，桌面烟花对应中位为 63.767 ms；v25 固定 DPR 1。新旧时序已改变，固定 q=4.5 的同时绽放数量也不同；这些数字衡量该时刻的绘制工作量，不等同于完整动画的平均帧率。
