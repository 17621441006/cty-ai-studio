# v26：以展示为先的性能整理

日期：2026-10-05。基准来源：v25 的 `4cb74cd07e34e14ac745a985bde27adac35d5962`。

## 主要修改

- 相册、房屋画廊、唱片机、作品目录、终端、搜索、桌面操作对话框及月之空间按入口加载。壁纸仅载入选中场景的绘制代码；具体游戏、Three.js、Python 与模型保持打开作品后才加载。
- 音频和视频不再预读整首/整段内容。播放、导入或操作进度条后按需要读取。播放进度与桌面、手机首页使用不同的状态订阅，进度更新不再重绘整个桌面。
- 每个窗口有独立动画调度器：最小化、被全屏应用覆盖、手机切换到其他应用、打开月之空间或浏览器转入后台时，停止相应画布的帧回调。恢复后延续模拟时间，不追赶后台经过的时间。高刷新率显示器不会使动画负担成倍增加。
- 本地 iframe 游戏和艺术漫游沿用可验证来源的可见性消息；艺术漫游隐藏后真正取消帧回调，减少逐帧修改标题和进度条的次数。视频隐藏后暂停；音乐允许继续后台播放。
- 满屏作品背后的壁纸休眠，电脑上的猫咪交互继续保留。城堡灯光使用预先计算的像素图集，现场不再扫描图片并创建上千张灯光画布；外滩房间灯光按 6 Hz 更新缓存，海港岛屿、栈桥复用静态图层。水面、灯带、车辆与猫咪仍是动态对象。
- 角色保留原始资产，另生成匹配桌面尺寸的 WebP 展示图。偶发魔法角色在对应事件开始接近时准备；猫咪特殊姿势在首次使用时加载。猫咪站位测量缓存 100 ms，窗口移动、图标整理、滚动和尺寸变化时失效。
- 静态 3D 场景只在视角、物件或设置改变时重绘；手机的房间阴影纹理设为 1024，保留桌面的 2048。

## 验证与边界

- TypeScript 检查和生产构建通过。
- `node scripts/qa/performance.cjs` 验证动画停止、恢复、销毁、后台可见性、虚拟时间、高刷新率上限，以及播放器进度更新隔离和禁用音频预加载。
- 使用真实绘制函数、软件 Canvas，在 1440×852 和 390×760 两种尺寸核对城堡、外滩、海港，以及猫咪缩图前后的画面。城堡灯光颜色、位置和场景构图保持；结果不等于真实浏览器的 GPU 帧率。
- 当前预览地址受访问策略限制，未运行浏览器端性能面板或真机触控测试。不能据此声称所有设备达到固定 FPS；应继续用用户实际手机与电脑核验。
- 外部马特洪峰、法罗群岛和三寸人间不能从父页面直接停止内部渲染；窗口不可见时释放其 iframe，恢复时重新载入。其相机位置可能重置。AI-cat / USACO 等外部学习页面保留会话和表单，性能也取决于原站。
- 云朵镇与长旅的专注计时使用真实时间；隐藏时暂停界面更新，恢复时依照原截止时间计算，不丢失专注时间。小游戏的状态继续保存在当前窗口内。
